## 🏛️ 2. Architectural Blueprint & Operational Guidelines

### 2.1. Framework & Platform Rules
- **Framework:** CFWheels 4.1.2 running on IIS 10.0 + Lucee CFML Engine.
- **Flat App Structure:** No `/public` folder; `Application.cfc` and `index.cfm` reside in root.
- **Reloading Production:** In production mode, application reloads require the password:
  ```
  http://cmsadmin.chelancounty.gov/[route]?reload=true&password=chelancms
  ```
- **Zero External Dependencies:** No jQuery, Bootstrap, FontAwesome, or Bower. Use native ES6+ vanilla JavaScript and modern CSS Grid/Flexbox.
- **Vector Icons:** Use the view helper `#svgIcon(name="...", size=..., class="...")#` for all icons (over 50 icons supported).
- **Custom Admin Dialogs (No Native `alert` / `confirm`):** Always use `window.adminAlert({ title, message, type })`, `window.adminConfirm({ title, message, type, confirmText, cancelText })`, `window.adminPrompt(...)`, and `window.showToast(msg, type)` defined in `javascripts/admin.js` instead of browser `alert()` / `confirm()`. Ensure page modals use a `z-index` below `100000` (e.g., `9990`) so `#adminPromptBackdrop` (`z-index: 100000`) renders on top.
- **CFML JSON Serialization & CSRF Rules:**
  - Always quote struct keys in CFML (`{ "success": true, "message": "...", "id": 123 }`) before calling `SerializeJSON()` so Lucee/ColdFusion does not uppercase keys.
  - On the client side consuming serialized CFML data, always provide case-insensitive key fallbacks (`item.title || item.TITLE`).
  - All `POST` AJAX requests (`fetch`) must include `"X-Requested-With": "XMLHttpRequest"` and `"X-CSRF-Token"` read from `document.querySelector('meta[name="csrf-token"]')`.
- **CFML `<cfoutput>` Hash Escaping Rule:** Any literal `#` in client-side JavaScript or inline CSS inside `<cfoutput>` blocks must be escaped as `##` (e.g., `'Alert ##' + id`, `color: ##ff0000;`). An unescaped `#` will cause a compile-time crash: `[coldfusion.util.RuntimeWrapper] Invalid CFML construct`.
- **IIS URL Rewrite Negation List Rule:** In `web.config`, the URL rewrite rule negates specific paths (`^/(cf_scripts|lucee|images|stylesheets|...)`). Never add `api` to this negation pattern if CFWheels is responsible for handling `/api/v1/...` REST endpoints.
- **SQL Server Filtered Index Rule:** Whenever executing `INSERT` or `UPDATE` via `queryExecute()` on tables that have filtered indexes (such as `WHERE [deletedat] IS NULL`), prepend `SET ANSI_NULLS ON; SET QUOTED_IDENTIFIER ON;` to the SQL statement and include `value: ""` whenever `null: true` is passed for integer parameters.

### 2.2. Strict WCAG 2.1 / 2.2 AA Rules
- **Color Contrast:** Normal text $\ge 4.5:1$, large text $\ge 3:1$, UI controls/borders $\ge 3:1$.
- **Focus Rings:** Always maintain visible focus (`outline: 2px solid var(--admin-primary) !important; outline-offset: 2px !important;`). Never use `outline: none` without replacement.
- **Labels:** Never leave an input without an explicitly linked `<label for="id">`. Multi-part inputs must have `<label class="sr-only">`.
- **Keyboard Navigation:** Every interactive element must be operable via `Tab`, `Enter`, and `Space`. Roving `tabindex` must be maintained on radio groups and star ratings.
